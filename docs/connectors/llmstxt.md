# llms.txt connector

Index the `llms-full.txt` of a list of websites, a single markdown file, or the pages an `llms.txt` index links to.

In Claude Code, `/passageway-add-source` from the [plugin](../guides/claude-code.md) installs this connector and writes its settings for you.
